# SellerFlowLive Parcel Checker

## Install

1. On the Mac, build the folder Chrome loads: `npm run build:extension`
   (it writes `chrome-extension-dist/`).
2. Open Chrome → `chrome://extensions` → turn on **Developer mode**.
3. Click **Load unpacked** → choose the `chrome-extension-dist` folder.
4. Click the extension icon, fill in the connection, tick **Check for all sellers**, click **Save**.
5. Keep these 3 tabs open and logged in: SellerFlowLive, the 7-11 seller page, the 7-11 store map.

After an update: run step 1 again, then click **Reload** on the extension card.
