# SellerFlowLive TikTok Grabber

This is a local Chrome extension for Windows sellers who need faster visible TikTok LIVE comment capture.

## Install

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Turn on `Developer mode`.
4. Click `Load unpacked`.
5. Select this folder: `chrome-extension`.
6. Click the extension icon and save:
   - Seller login email
   - Live server URL

## Use

1. Open SellerFlowLive dashboard in one tab.
2. Open any TikTok LIVE in another tab or split screen.
3. A small SellerFlowLive panel appears on TikTok.
4. If needed, type the seller email and press Save.
5. The extension auto-sends visible LIVE comments to SellerFlowLive.

Keep the TikTok LIVE page visible during selling. No TikTok username setup is needed for testing.
