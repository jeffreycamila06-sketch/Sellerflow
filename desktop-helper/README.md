# SellerFlowLive Desktop Helper Lite

This is the first Windows helper for sellers who need faster TikTok live comment capture without a Chrome extension.

## What it does

- Opens Chrome or Microsoft Edge with a safe helper profile.
- Seller opens the TikTok LIVE page in that browser.
- Helper reads visible TikTok comments from the page.
- Helper sends comments to the SellerFlowLive live server.
- SellerFlowLive dashboard keeps handling 1-click order and printing.

## How to run

1. Open `Start SellerFlowLive Helper.bat`.
2. A browser page opens at `http://127.0.0.1:4788`.
3. Enter seller email, live account label, and server URL.
4. Paste TikTok LIVE URL or leave blank and open it manually.
5. Click `Start Helper Browser`.
6. Open SellerFlowLive dashboard in another window and keep it logged in.

## Notes

- This is a helper, not a full desktop app.
- It is made to stay light for older laptops.
- If TikTok changes its website layout, the comment reader may need updates.
- The helper does not store TikTok password or SellerFlowLive password.
